- [Build, deploy and on-device verification gotchas](memory/gotchas-build.md) — Build, deploy and verification traps paid for once already: EmbedAssembliesIntoApk or Android runs stale code, chained installs hiding a failed build, stale screencaps, a shared emulator, devicectl error 7, XAML tooling that fails silently
- [Firebase / Firestore reverse-engineering gotchas](memory/gotchas-firebase.md) — Firebase/Firestore traps from the LogTRAK capture: the native SDK speaks gRPC so an HTTP proxy sees nothing, keys are bundle-restricted, orderBy+where needs a composite index, list is denied but a filtered query is not.
- [MAUI runtime UI & interaction gotchas](memory/gotchas-ui.md) — MAUI runtime traps paid for once: handler mappers re-run and loop the layout, DescendantAdded goes quadratic, anything interactive in a ScrollView must claim the touch stream on end AND cancel, haptics need a runloop yield.
