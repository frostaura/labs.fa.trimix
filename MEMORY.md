# MEMORY — Labs/projects/fa.trimix

- [Current state](memory/state.md) — Serverless on-device API-sync-only dive log. Garmin + ScubaPro verified live, Suunto summary-only. No product work is untracked or uncommitted any more; Core suite real and green (2026-09-11). Five shipped behaviours unseen on the iPhone.
- [Live decisions — product, economics and legal posture](memory/decisions.md) — Serverless and on-device is a product invariant, not a phase: no backend, no auth, API sync the only dive-entry path, entitlements client-trusted and piratable by choice, and reverse-engineered connectors the primary surface by override.
- [Connector / reverse-engineering decisions](memory/decisions-connectors.md) — Every shared-corridor assumption here was wrong when finally captured: ScubaPro is LogTRAK/Firebase not MySSI (so Mares is suspect), Suunto is Sports Tracker not cloudapi, Garmin needs no FIT, MFA divers unsupported by design.
- [Haptics, motion and perceived performance](memory/decisions-haptics.md) — Feel is engineered: a six-cue semantic port (never MAUI Essentials), cues on intent coalesced inside 120 ms, the HapticCommand decorator that must not be simplified back, Taptic Prepare, chart and merge off the UI thread.
- [Multi-provider sync & merge decisions](memory/decisions-sync.md) — Overlapping dives merge on padded time-interval overlap (0.30 x geometric mean, clamped 120-600 s); user-set priority picks the winner, fidelity only the tie-break; unlink hard-deletes; auto-sync on every link; flash fix reverted.
- [UI & layout decisions](memory/decisions-ui.md) — Text inputs and the entry-point map are per-platform BY DESIGN — do not unify. CarouselView rejected for dive-detail; the chip strip is gone so swipe is the only pager, an open iOS risk; chart markers removed; skeleton until loaded.
- [Gotchas — durability and capture hygiene](memory/gotchas.md) — Never `git clean` here: the three vendor contracts came from credentialed captures that were then deleted, so they are irreplaceable — and a live capture holds the founder's plaintext vendor password until it is swept.
- [Gotchas — build and on-device deploy](memory/gotchas-build.md) — Build, deploy and verification traps paid for once already: EmbedAssembliesIntoApk or Android runs stale code, chained installs hiding a failed build, stale screencaps, a shared emulator, devicectl error 7, XAML tooling that fails silently
- [Gotchas — connector verification](memory/gotchas-connectors.md) — Only Garmin and ScubaPro are verified end-to-end; Suunto degrades to a summary-only dive and the rest are fixture-only guesses. A vendor cloud is a captured contract — every shared-corridor assumption made here has been wrong.
- [Gotchas — Firebase/Firestore](memory/gotchas-firebase.md) — Firebase/Firestore traps from the LogTRAK capture: the native SDK speaks gRPC so an HTTP proxy sees nothing, keys are bundle-restricted, orderBy+where needs a composite index, list is denied but a filtered query is not.
- [Gotchas — MAUI runtime UI](memory/gotchas-ui.md) — MAUI runtime traps paid for once: handler mappers re-run and loop the layout, DescendantAdded goes quadratic, anything interactive in a ScrollView must claim the touch stream on end AND cancel, haptics need a runloop yield.
- [Open questions](memory/questions.md) — All founder-owned: can iOS page the dive-detail sections with the chips gone; M3 needs a telemetry beacon a serverless app cannot provide; is the thinnest-TAM bet worth field-testing; name clearance unrun; CAC never measured.
- [Watch list](memory/watch.md) — Unpaid debts: no adversarial re-review of the rebuilt tree before M3, dead backend DTOs and Sites leftovers still shipping in Trimix.Contracts, and a physical-iPhone deploy path that is unblocked and has never been used.
- [Worklog — session index](memory/worklog.md) — Session pointers only, newest first. Only the 2026-08-21 durability push and the 2026-07-30 Garmin capture still change how this program is read; the July rebuild entries survive as origin, not as description.
