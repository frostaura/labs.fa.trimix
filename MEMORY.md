## Live decisions
- **Aggregator pivot (2026-07-05, founder-directed):** import is a multi-source normalization hub, not BLE-only.
- **Legal override on reverse-engineered connectors (2026-07-05).** A 13-agent landscape sweep found **no clean published cloud API returns a dive profile** from any major vendor, and **PADI/SSI have no logbook-write API**. Apple HealthKit is the only clean cloud surface; file import and BLE-direct-from-owned-hardware are the other clean channels. Vendor-cloud pull and PADI/SSI push therefore require reverse-engineering credential-gated backends — *a ToS/CFAA-gray-area that knowingly **fails the program's own gate-3 "integrated legally"***. This was flagged to the founder explicitly and the founder **directed shipping them as real, enabled features** — a parent-controlled legal/IP/brand call. **This is a documented, accepted risk, not an oversight.** The three user-protecting guardrails in `CLAUDE.md` are independent of the override and stand.
- **Name "Trimix" was founder-picked 2026-07-03** from the PRD candidate list. The PRD itself flags it as likely-high collision risk in the dive space. Predecessors: DeepLog (unavailable — a live iOS competitor since 2026-04) and Wreckline (survives only in a design-project filename).
- **Android first** (2026-07-03) because the host macOS is a beta OS with Xcode-toolchain risk.
- **The .NET MAUI client stack override was root-reviewed 2026-07-03**, superseding both the React mandate and the PRD's Swift/Kotlin dual-native exception. Settled; do not relitigate.
- **PostGIS was explicitly rejected** in favour of a bounding-box prefilter plus in-memory haversine in `Sites/GeoMath.cs`, so integration tests run hermetically on SQLite.

## Gotchas
- **~46k LOC of ~5 days' multi-agent work exists in exactly one place: uncommitted, unversioned, on an iCloud-synced local disk with no remote.** A single `git clean -fdx` or an iCloud eviction destroys the entire program. **This is the highest-severity item in all of Labs. `git add -A && git commit`, create the remote, push — before anything else in this repo.**
- **`.github/` does not exist.** Zero CI, zero CD, zero reproducible build. Every "gate PASSED" claim rests on a local `dotnet build`/`dotnet test` on one Mac with an ad-hoc user-space toolchain.
- **BLE is real plumbing over an unvalidated protocol.** 3,264 LOC including real CoreBluetooth (549) and Android BLE LE (438) transports and clean-room fixture-tested parsers for Suunto/ScubaPro/Aqualung/Mares. But **`ShearwaterProtocol.cs` — the flagship vendor — parses the *simulator fixture* frame format, not the real Shearwater protocol.** Its own header says so: *"⚠ M3 RISK: parsing is validated against the simulator fixture contract only."* Exactly one value is pinned as public fact: the Shearwater service UUID `fe25c237-0ece-443c-b0aa-e02033e7029d` (from libdivecomputer/Subsurface). All other vendors are name-hint-only with null service UUIDs; handshake bytes are labelled deploy inputs and **explicitly never guessed**. **No BLE code has ever touched a dive computer.**
- **A revenue-killing bug worth remembering:** Apple StoreKit bundle receipts are multi-KB and overflowed the `varchar(2048)` unique btree key on `Receipts.Token` — *every real iOS purchase and restore would have 500'd with no entitlement granted*. Fixed by widening to `text` with uniqueness moved to a fixed-length `TokenSha256` (migration `WidenReceiptToken`). Do not narrow that column again.
- Other hostile-QA finds, all fixed and all worth not re-introducing: the connector master-switch was inert (reverse-eng connectors were one consent-tap from going live despite the flag reading false); GDPR delete never called the server; unbounded substring vendor matching made "Lantern" match "Tern"; a committed DB credential sat in base `appsettings.json`.
- `Trimix.Core/Protocols/` and `Trimix.Core/Services/` contain only `.gitkeep` — dead scaffold dirs. Untracked `bin\Debug` artifacts exist with a **literal backslash** in the directory name (Windows-path leakage); gitignored `bin/` does not match `bin\Debug`, so they show as untracked content. 27 NU1608 warnings come from Xamarin.AndroidX transitive drift, deferred as cosmetic.
- **`[CAC_PER_PAYER = TBD]` is still a literal placeholder** in the economics — no CPI test has ever been run. Net-of-fee math is done ($14.99 → $12.74 at 15% / $10.49 at 30%, blended ~$13/payer).
