# Live work — 2026-07-29 (You-tab consolidation + Sites capability removal)

## Live work — 2026-07-29 (You-tab consolidation + Sites capability removal)

Two founder directions, in order:
- **Settings page folded into the You tab; demo mode removed; nav freeze fixed — committed `8ad5241`, pushed.** The standalone Settings page/VM/route/gear were deleted; its Privacy (export + factory reset) and About (disclaimer + replay onboarding) cards moved onto the You tab (which already duplicated plan + units). Also on the You tab: the **profile card (avatar / editable name / cert line) was removed** (single-device, no accounts); the **Metric|Imperial toggle desync** was fixed (selection colour now binds off `IsMetric` via `UnitSegmentColorConverter` on a `UnitSegmentButton` whose Pressed VisualState no longer fights the binding — the old DataTrigger left both segments stuck mint after a switch-and-back); the **EAN badge pops (ScaleTo 1.3×) while the slider is dragged**; and **21% O₂ now reads "AIR"** not "EAN21".
- **Sites capability removed entirely.** Founder: "this is a logbook and a sync tool." Deleted `SitesPage`/`SiteDetailPage`(+VMs), `Sites/SiteAtlas.cs` (14-site bundled atlas), `SiteDtos.cs`, `SiteAtlasTests`, `tab_sites.svg`; removed the Sites tab (now **2-tab bar Log · You**), `Routes.Sites`/`SiteDetail`/`Params.SiteId`, DI registrations, `SiteSubtitle`/`SiteDepthRange` converters, `IconSites` glyph, `DiveStats.MostDivedSites`+`SiteFrequency`, `EntitlementGate.CanContributeSites`, ImportService site auto-match (+ the now-unused `ILocationService`/`SiteAtlas`/`ILogger` deps), the DiveDetail "NEAR THIS SITE" carousel + site title, and the logbook row's site line (rows now **headline the dive date**; dive detail titles **"Dive #N"**).

The **frozen `site_*` funnel constants stay** (`site_viewed`, `site_contribution_*`, `site_matched_bool`, `site_id`) — additive-only taxonomy. The orphaned server-era `ContributionDtos`/`ApiRoutes.Sites` contract shapes were left (already dead since the serverless pivot; not the app capability).
  - **Why:** founder re-scoped Trimix to logbook + sync; "enrich" left the core loop.

Verified live on Android: Get started → How it works → Continue → **Logbook, no biometric page**.
- **Settings** (per founder answers): kept Export/Delete simplified (Delete no longer "signs out"); added **"Replay onboarding"** (data-preserving re-show, ABOUT card) and **"Reset app"** (destructive factory reset — wipes dives+links+tier+prefs → onboarding; confirm dialog carries the disclaimer that already-synced dives are NOT removed from downstream PADI/SSI). Seamless.

They instantiate at no runtime path; they belong to the separate "dead server DTO" cleanup already tracked below.

## Live work — 2026-07-29 (bottom-sheet overlay polish + commit)

Founder UI polish on the Logbook "ADD" shelf, all shared through one reusable control, deployed to **all three targets** (Android emulator, iOS sim, physical iPhone 17 Air):
- **Reusable sheet architecture.** The add + streaming-sync sheets are one `Controls/BottomSheet` hosted in a `Controls/TransparentModalPage` (see `Pages/SheetOverlayPage`) pushed OVER the whole window — so each card overlays the Shell tab bar with the menu dimmed *underneath* (a page-hosted sheet can't: the tab bar sits below it on Android / floats over it on iOS). Reaches the true device bottom on both platforms (iOS negative-margin bleed past the safe-area inset; Android consumes window insets in `TransparentModalPage` so MAUI doesn't shrink the modal into the nav bar).
- **Native frosted backdrop** (`Controls/BlurView` + per-platform `BlurViewHandler`). iOS: live `UIVisualEffectView` scrubbed to partial intensity via a paused `UIViewPropertyAnimator` (`UIBlurEffectStyle.Dark` = black tint, not the grey `*MaterialDark`). Android has no live backdrop blur, so it snapshots the DecorView and applies a hardware gaussian `RenderEffect.CreateBlurEffect` (API 31+; downscale/upscale fallback pre-31) — smooth, matching iOS. A black `#59000000` scrim over both keeps the frost black while content stays softly visible.
- **Removed** the sonar sync button from the top-right of every page (the shelf carries that action now) and the "Connect your computer or dive center" empty-state CTA.
- **Header re-render fix.** Closing the shelf replayed `TrimixPage`'s `screenIn` entrance on the Logbook (header "slid back in") because `OnAppearing` re-fires when the transparent modal pops. Fix: `TrimixPage.SuppressNextScreenIn()` (opt-in, one-shot) + a `_returningFromOverlay` guard in `LogbookPage` — the overlay round-trip skips both the entrance and the redundant `LoadCommand` reload (the page never left the screen; a sync reloads itself in `OnSyncPropertyChanged`).
- **Shelf slide doubled in speed** (founder: "half as long", across the board). `BottomSheet` `SlideMs 380→190`, `ScrimMs 300→150`, drag spring-back `180→90`. One control ⇒ both sheets app-wide.
- Evidence: 343/343 Core tests green; Android + iOS TFMs both build 0 errors; header-fix behaviour live-verified on Android (header pixel-stable pre-open vs post-close), smooth Android blur screenshot-confirmed.
